## Short description (EN)
15 retro pixel-art games in one firmware for the M5StickC Plus2: tilt-controlled arcade, racing, flying, puzzle and more, with a daily challenge, medals, skins and a 2-player pass-the-device mode.

## Description (EN)
**AD Arcade** turns your M5StickC Plus2 into a pocket arcade console with a clean 16-bit pixel-art look.

**15 games:** Chrome Dino, Flap Bird, Meteors, Maze, Breakout, Invaders, Slalom, Stack, Racing, Flight, River, Fish, Tetris, Snake, Lunar Lander.

**Features**
- Tilt controls (built-in MPU6886) with a guided first-boot calibration
- Daily Challenge: one game and one seed per day, 3 tries, streak and 7-day history
- 2 Players mode: pass the device, same start for both, 1 round or best of 3
- Medals (bronze / silver / gold) per game, Easy / Normal / Hard difficulty
- Skins for the hero of several games, with a live preview screen
- Stats, built-in music player (custom songs over Wi-Fi), settings (brightness, volume, sleep, language EN/FR, date and time)
- Retro menu with a colourful animated background

**Controls:** M5 button = select / action, side button = next, power button = back / previous. Hold power (or A+B) to return to the menu.

**Install:** flash the .bin at address 0x0 (M5Burner does it for you). On first boot choose the language, follow the calibration, then set the date and time.

Free and open source (GitHub release coming soon). Made by ADdev.

## Description (FR)
**AD Arcade** transforme ton M5StickC Plus2 en console d'arcade de poche au style pixel art 16 bits.

**15 jeux :** Chrome Dino, Flap Bird, Meteors, Labyrinthe, Casse-briques, Invaders, Slalom, Stack, Course, Avion, Rivière, Poisson, Tetris, Snake, Alunissage.

**Fonctions**
- Contrôle par inclinaison (MPU6886) avec calibrage guidé au premier démarrage
- Défi du jour : un jeu et une graine par jour, 3 essais, série et historique sur 7 jours
- Mode 2 joueurs : on se passe la console, même départ pour les deux, 1 manche ou 3
- Médailles bronze / argent / or par jeu, difficulté Facile / Normal / Difficile
- Skins pour le héros de plusieurs jeux, avec écran d'aperçu en direct
- Stats, lecteur de musique (morceaux perso via Wi-Fi), réglages (luminosité, volume, veille, langue FR/EN, date et heure)
- Menu rétro avec fond animé coloré

**Commandes :** bouton M5 = valider / action, bouton latéral = suivant, bouton power = retour / précédent. Maintenir power (ou A+B) pour revenir au menu.

**Installation :** flasher le .bin à l'adresse 0x0 (M5Burner s'en charge). Au premier démarrage : langue, calibrage, puis date et heure.

Gratuit et open source (version GitHub bientôt). Créé par ADdev.
