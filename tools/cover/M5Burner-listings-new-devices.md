# AD Arcade - M5Burner listings (English only)

Notes for the listings:
- Same firmware as AD Arcade 1.7.2 (the Plus2 version), compiled for each device.
- Upload one .bin per listing (merged image, flashed at 0x0 by M5Burner).
- Cover: use the 1280x720 image (or the 800x800 one) with the matching device name.

====================================================================
## 1) AD Arcade for M5StickC Plus
Name: AD Arcade for M5StickC Plus   |   Version: 1.7.2   |   File: AD-Arcade-M5StickCPlus-v1.7.2.bin
Cover: AD-Arcade-StickCPlus-cover-1280x720.png

### Firmware description
```
**AD Arcade for M5StickC Plus**

>  **Official Github Open Source**; [AD-Arcade](https://github.com/ADdevx/AD-Arcade-M5StickCPlus2)

*A mini arcade console for your M5StickC Plus with a clean 16-bit pixel-art look. It comes with 15 games, a music player and a colourful retro menu. Flash it, press a button and start playing.*

*This is a first release for this device. It has been tested in simulation, but not yet on real hardware. Your feedback is welcome: leave a comment here or open an issue on GitHub!*

**Games**
Chrome Dino, Flap Bird, Meteors, Maze, Breakout, Invaders, Slalom, Stack, Racing, Flight, River, Fish, Tetris, Snake and Lunar Lander.

**Features**

Tilt controls using the built-in motion sensor, with a guided calibration at first boot
Daily Challenge: one game per day, 3 tries, streak and 7-day history
2 Players mode: pass the device around
Bronze, silver and gold medals for every game
Easy, Normal and Hard difficulty
Skins with a live preview screen
Stats screen
Background music in every game, which you can turn off
Music player with classic tunes
Retro intro and a scrolling menu
English and French
Saved high scores
Settings for brightness, volume, sleep time, date and time

**Controls**
A (M5 button) to select, B (side button) for the second action, PWR to pause. Hold A and B together for about 1 second to go back to the menu.
```

### Version notes
```
- First release (tested in simulation, feedback welcome) for the M5StickC Plus, based on AD Arcade 1.7.2
- Retro pixel-art look with colourful animated backgrounds
- First-boot wizard: language, calibration, date and time
- Skins screen with live preview
```

## 3) AD Arcade for M5Cardputer
Name: AD Arcade for M5Cardputer   |   Version: 1.7.2   |   File: AD-Arcade-M5Cardputer-v1.7.2.bin
Cover: AD-Arcade-Cardputer-cover-1280x720.png

### Firmware description
```
**AD Arcade for M5Cardputer**

>  **Official Github Open Source**; [AD-Arcade](https://github.com/ADdevx/AD-Arcade-M5StickCPlus2)

*A mini arcade console for your M5Cardputer with a clean 16-bit pixel-art look. It comes with 15 games, a music player and a colourful retro menu. Flash it, press a key and start playing.*

*This is a first release for this device. It has been tested in simulation, but not yet on real hardware. Your feedback is welcome: leave a comment here or open an issue on GitHub!*

**Games**
Chrome Dino, Flap Bird, Meteors, Maze, Breakout, Invaders, Slalom, Stack, Racing, Flight, River, Fish, Tetris, Snake and Lunar Lander.

**Features**

Keyboard controls: the arrow keys replace tilt (if your Cardputer has a motion sensor, it is used instead)
Daily Challenge: one game per day, 3 tries, streak and 7-day history
2 Players mode: pass the device around
Bronze, silver and gold medals for every game
Easy, Normal and Hard difficulty
Skins with a live preview screen
Stats screen
Background music in every game, which you can turn off
Music player with classic tunes
Retro intro and a scrolling menu
English and French
Saved high scores
Settings for brightness, volume, sleep time, date and time

**Controls**
Enter or Space = A (select), Tab = B (second action), Del = PWR (pause), arrow keys ; , . / = tilt. Hold Del for 1.5 seconds (or Enter and Tab together) to go back to the menu.
```

### Version notes
```
- First release (tested in simulation, feedback welcome) for the M5Cardputer, based on AD Arcade 1.7.2
- Keyboard controls (arrow keys act as tilt)
- Retro pixel-art look with colourful animated backgrounds
- Skins screen with live preview
```
