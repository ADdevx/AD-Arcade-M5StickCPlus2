## AD Arcade v1.5

A new daily challenge, a 2 player mode and a lot more to unlock.

**New**
- Daily Challenge: a new game every day, 3 tries, streak and 7-day history
- 1-2 Players: solo mode, or pass the M5 around with the same start for both (best of 3 if you like)
- Stats screen
- Difficulty setting (Easy / Normal / Hard) with separate records and medals for Hard
- Skins unlocked with medals
- Volume with 5 levels, Date setting, louder game music

**Install**
Flash with [M5Burner](https://burner.m5stack.com/Q5BB26), or flash `AD-Arcade-M5StickCPlus2-v1.5.bin` at address `0x0`.

The first time you open the Daily Challenge, set today's date (the clock keeps it afterwards).
